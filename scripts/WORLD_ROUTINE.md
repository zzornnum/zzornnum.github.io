# 해외뉴스 정리 지침

매일 아침 7시 50분에 실행되는 Claude 예약 작업(소형 모델)의 지침입니다. 토큰을 아끼기 위해 **웹 검색이나 기사 원문 열람은 하지 않고**, 수집 파일에 있는 제목과 요약만으로 작업합니다.

## 할 일

1. 오늘 날짜(KST)를 구한다: `TZ=Asia/Seoul date +%F`. `data/world/<오늘>.json`이 이미 있으면 종료한다.
2. `data/world/raw/<오늘>.json`(GitHub Actions가 무료 RSS에서 모은 영문 헤드라인)을 읽는다.
   - 없으면 수집을 요청한다: `TZ=Asia/Seoul date +%F > data/requests/world.txt` 후 이 파일만 커밋(`해외뉴스 수집 요청: <오늘>`)해 main에 push한다. 30초 간격으로 `git pull --rebase`하며 최대 8분 기다린다. 그래도 없으면 아무것도 커밋하지 않고 종료한다.
3. 한국 주식 투자자에게 중요한 **12~15건**을 고른다.
   - 우선순위: 중앙은행·금리·물가·고용 등 거시지표 → 무역·관세·환율 → 주요 증시·원자재 → 반도체·자동차·배터리·조선 등 한국 주력 산업과 관련된 글로벌 기업 소식 → 중국 경기·정책.
   - 제외: 정치·사건사고·생활·연예 등 경제와 무관한 기사, 같은 사건을 다룬 중복 기사(가장 정보가 많은 1건만).
   - 지역별로 고르게: 미국 4~6, 유럽 2~4, 중국 2~3, 아시아·글로벌 2~3건(해당 기사가 부족하면 조정).
4. 고른 기사마다 다음을 쓴다.
   - `title`: 한국어 제목(자연스러운 기사 제목체, 40자 이내).
   - `summary`: 한국어 요약 2~3문장. 수집 파일의 `title`과 `summary`에 있는 사실만 쓰고, 없는 숫자·사실을 덧붙이지 않는다. 마지막 문장에 한국 시장·업종에 주는 의미를 짧게 덧붙여도 되지만 추측은 "~할 수 있다" 정도로 쓴다.
   - `original`: 영문 원제목 그대로.
   - `region`, `source`, `url`, `published`: 수집 파일 값 그대로.
5. 아래 형식으로 `data/world/<오늘>.json`을 쓰고 `python -m json.tool`로 검증한다.
6. 이 파일만 커밋(`해외뉴스: <오늘>`)해 main에 push한다. 거절되면 `git pull --rebase` 후 다시 push한다.

## 파일 형식

```json
{
  "date": "2026-10-16",
  "generatedAt": "2026-10-16T07:50:00+09:00",
  "items": [
    {
      "region": "미국",
      "title": "9월 생산자물가 6.3% 급등…2022년 이후 최대",
      "summary": "...",
      "original": "Wholesale prices jumped 6.3% annually in September, biggest gain since 2022",
      "source": "CNBC",
      "url": "https://...",
      "published": "2026-10-16T01:15+09:00"
    }
  ]
}
```

- `region`은 `미국`, `유럽`, `중국`, `아시아`, `글로벌` 중 하나. 기사 내용이 다른 지역에 관한 것이면 수집 파일 값 대신 내용에 맞는 지역으로 바꿔도 된다.
- 위 파일(과 2단계의 `data/requests/world.txt`) 외에는 수정하지 않는다.
