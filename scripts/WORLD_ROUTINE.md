# 해외뉴스 정리 지침

매일 아침 7시 50분에 실행되는 Claude 예약 작업(소형 모델)의 지침입니다. 토큰을 아끼기 위해 **웹 검색이나 기사 원문 열람은 하지 않고**, 수집 파일에 있는 제목과 요약만으로 작업합니다.

## 할 일

1. 오늘 날짜(KST)를 구한다: `TZ=Asia/Seoul date +%F`. `data/world/<오늘>.json`이 이미 있으면 종료한다.
2. `data/world/raw/<오늘>.json`(GitHub Actions가 무료 RSS에서 모은 영문 헤드라인)을 읽는다.
   - 없으면 수집을 요청한다: `TZ=Asia/Seoul date +%F > data/requests/world.txt` 후 이 파일만 커밋(`해외뉴스 수집 요청: <오늘>`)해 main에 push한다. 30초 간격으로 `git pull --rebase`하며 최대 8분 기다린다. 그래도 없으면 아무것도 커밋하지 않고 종료한다.
3. 한국 주식 투자자에게 중요한 **12~15건**을 고른다. 기사는 수집 파일의 `id`로 가리킨다.
   - 우선순위: 중앙은행·금리·물가·고용 등 거시지표 → 무역·관세·환율 → 주요 증시·원자재 → 반도체·자동차·배터리·조선 등 한국 주력 산업과 관련된 글로벌 기업 소식 → 중국 경기·정책.
   - 제외: 정치·사건사고·생활·연예 등 경제와 무관한 기사, 같은 사건을 다룬 중복 기사(가장 정보가 많은 1건만).
   - 지역별로 고르게: 미국 4~6, 유럽 2~4, 중국 2~3, 아시아·글로벌 2~3건(해당 기사가 부족하면 조정).
4. 고른 기사마다 **`id`, `title`, `summary` 세 가지만** 쓴다. 링크·언론사·지역·시간·영문 제목은 쓰지 않는다(5단계 스크립트가 수집 파일에서 정확히 채운다).
   - `id`: 수집 파일의 해당 기사 `id`(예: `w12`). 반드시 그 기사의 `id`여야 한다.
   - `title`: 그 기사의 한국어 제목(자연스러운 기사 제목체, 40자 이내).
   - `summary`: 그 기사의 한국어 요약 2~3문장. **그 기사의 `title`과 `summary`에 있는 사실만** 쓴다. 다른 기사 내용을 섞지 않는다. 마지막 문장에 한국 시장·업종에 주는 의미를 짧게 덧붙여도 되지만 추측은 "~할 수 있다" 정도로 쓴다.
   - **정확성 규칙 (반드시 지킨다)**
     - 숫자(%, 달러, 조·억, 연도)는 원문 숫자를 그대로 옮긴다. trillion=조, billion=10억(예: $40 trillion = 40조 달러, $2 billion = 20억 달러). 원문에 없는 숫자는 쓰지 않는다.
     - 방향을 뒤집지 않는다: gain·rise·jump·surge=상승·급등, fall·drop·slump=하락·급락, hike=인상, cut=인하, hold=동결.
     - 용어: yields=금리(국채 수익률), inflation=물가 상승률, PPI=생산자물가, CPI=소비자물가, debt=부채, deficit=적자, tariff=관세.
     - 사람·기관 이름은 원문 표기(예: Warsh=워시, Fed=연준, ECB=유럽중앙은행).
   - **검토:** 쓰고 나서 기사마다 그 `id`의 원문 `title`·`summary`를 다시 읽고, 한국어 제목·요약이 같은 기사를 말하는지와 위 규칙을 확인해 고친다.
5. `{"items": [{"id": "w12", "title": "...", "summary": "..."}, ...]}`를 `data/world/<오늘>.json`에 쓰고 `python scripts/build_world.py <오늘>`을 실행한다. 이 스크립트가 링크·언론사·지역 등을 채워 파일을 완성한다. 오류(없는 id, 중복 등)가 나오면 고치고 다시 실행한다.
6. 완성된 파일만 커밋(`해외뉴스: <오늘>`)해 main에 push한다. 거절되면 `git pull --rebase` 후 다시 push한다.

## 파일 형식

```json
{
  "date": "2026-10-16",
  "generatedAt": "2026-10-16T07:50:00+09:00",
  "items": [
    {
      "id": "w3",
      "region": "미국",
      "title": "9월 생산자물가 6.3% 급등…2022년 이후 최대",
      "summary": "...",
      "original": "Wholesale prices jumped 6.3% annually in September, biggest gain since 2022",
      "source": "CNBC",
      "url": "https://...",
      "published": "2026-10-16T01:15+09:00"
    }
  ]
}
```

- 위는 5단계 스크립트가 만든 완성본 형식이다. 루틴이 직접 쓰는 것은 `id`·`title`·`summary`뿐이다.
- 위 파일(과 2단계의 `data/requests/world.txt`) 외에는 수정하지 않는다.
